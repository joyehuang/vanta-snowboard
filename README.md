# VANTA — Beyond the Line

A concept snowboard landing page built with React, TypeScript, Three.js and GSAP on Vinext.

## Development

```sh
npm install
npm run dev
```

## Validation

```sh
npx tsc --noEmit
npm run build
```

The snowboard is a procedural Three.js mesh with a curved nose/tail, metallic edge, mounting inserts, and generated topsheet/base textures. Drag horizontally or use arrow keys to inspect; choose a colorway and return to the hero to view it. Reduced-motion settings disable ambient and scrolling animations.

This is a concept collection, not a live store. Size selection configures the product preview; no checkout or payment is connected.
